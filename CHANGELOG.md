# Changelog

All notable changes to this project will be documented in this file.

## [1.4.0] - 2025-11-15
### Added
- Styling controls for review card background, text, meta line, dot navigation colour, and horizontal spacing via the settings page and shortcodes.

### Changed
- Applied CSS custom properties for carousel theming so colour and spacing updates propagate to empty/error states.

## [1.3.0] - 2025-11-08
### Added
- Autoplaying carousel behaviour with configurable delay, transition timing, and dot navigation that highlights the active review.
- Settings fields to control autoplay delay and scroll animation duration.

### Changed
- Rebranded the plugin to **SDC Review Carousel** with refreshed shortcode names, assets, and documentation.
- Simplified the carousel UI by removing previous/next buttons in favour of accessible dot navigation that appears on hover/focus.

## [1.2.0] - 2025-10-24
### Added
- Reviews carousel shortcode with rating filters, accessible controls, and Elementor guidance.
- Front-end carousel assets that respect `prefers-reduced-motion` and expose responsive slide counts.

### Changed
- Documented Elementor usage and shortcode attributes for the new carousel experience.

## [1.1.0] - 2025-09-17
### Added
- Comprehensive README covering installation, configuration, shortcode options, and caching guidance.
- CHANGELOG.md to track future updates.

### Changed
- Rebranded the plugin as **SDC GMB Review Badge** with Stoke Design Co author details.
- Updated option keys, shortcode names, CSS classes, and documentation to reflect the new brand.
- Improved shortcode output with clearer accessibility labelling and legacy shortcode aliases.

## [1.0.0]
### Added
- Initial release with shortcode-driven Google Business Profile rating badge and caching controls.
